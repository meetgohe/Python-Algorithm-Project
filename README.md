# 🌳 MST Algorithm Visualizer (Prim & Kruskal)

A Python GUI application to create weighted graphs and visualize the Minimum Spanning Tree (MST) using Prim’s and Kruskal’s algorithms.


## 📌 Overview

This project allows users to:

- Add weighted edges
- Remove edges
- Visualize graphs
- Run Prim’s Algorithm
- Run Kruskal’s Algorithm
- Save and load graph data (JSON format)

Built using:
- Tkinter (GUI)
- NetworkX (Graph operations)
- Matplotlib (Visualization)


## 🧠 Algorithms Used

- Prim’s Algorithm
- Kruskal’s Algorithm
- Graph Connectivity Check


## 🚀 Features

✔ Interactive GUI  
✔ Weighted graph creation  
✔ MST visualization  
✔ JSON save/load support  
✔ Error handling
